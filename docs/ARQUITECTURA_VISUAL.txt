FORM FLOW (Contact):
────────────────────
1. User fills form at /[locale]/contacte
2. Frontend validation (email, required fields)
3. POST /api/contact
   - Rate limit check: 3 req/min/IP → 429 if exceeded
   - Honeypot: if website !== empty → 200 OK (silent for bots)
   - Field validation: name, email, phone, message lengths
   - Sanitization: stripCRLF, escapeHtml (security)
4. Fetch POST to Formspree: https://formspree.io/f/maqvbrpr
5. Return 200 OK or error
6. Frontend: Show "Message sent!" or error message

STYLING ARCHITECTURE:
─────────────────────

  - @keyframes for animations

  - Extends dark mode colors from CSS vars
  - Custom spacing: margin: 48px
  - Custom maxWidth: container-max: 1440px
  - Custom animation: marquee
  
Components:
  - Framer Motion: whileInView, initial, transition
  - Tailwind utilities: hover:, dark:, sm:, md:, etc
  - Canvas/WebGL: THREE.js shaders

SECURITY MEASURES:
──────────────────
✓ Rate limiting: 3 POST /api/contact per minute per IP
✓ Honeypot: Hidden "website" field (catches bots)
✓ HTML escaping: escapeHtml() on all form inputs (XSS prevention)
✓ CRLF sanitization: stripCRLF() on name (header injection prevention)
✓ Email validation: Regex pattern check
✓ Field length validation: name ≤200, message 5-5000
✓ Dark mode only: No light mode CSS leakage
✓ No external scripts: No tracking, no ads, no third-party cookies

I18N SYSTEM:
────────────
- messages/{ca,es,en}.json: ~300 keys each
- Namespaces: hero, services, pillars, contact_page, clients_page, etc
- Access: const t = useTranslations('namespace'); t('key')
- Dynamic: useLocale() for current language
- Routing: URL-based (/ca/*, /es/*, /en/*)
- Middleware: Detects and routes automatically
